# راهنمای تست و پذیرش UI — خاتمه درس عملی کاربردی / مشاهده فیلم‌ها

**مخاطب:** اپروتور / QA  
**فرایندها:** `film_observation_ta_attendance_completion` (SOP ۷۵) و `film_observation_course_completion` (SOP ۶۴)  
**مرجع SOP:** `metadata/process_registry/processes/film_observation_ta_attendance_completion/SOP_document.txt`

---

## پیش‌نیاز

- ورود با نقش **مدرس** (`instructor`) در lane **پنل مدرس** (`/panel/portal/staff/instruction`)
- یک instance فعال در state `grades_entry` برای هر فرایند (با `course_code` در context)
- برای فرایند ۶۴: ورود **دانشجو** و باز کردن همان instance در تب فرایندها

---

## تست فرایند ۷۵ — مشارکت / حضور / TA

1. از کارتابل pending، instance فرایند ۷۵ را باز کنید.
2. بررسی کنید پنل `film-observation-ta-attendance-panel` نمایش داده می‌شود.
3. جدول دانشجویان باید از roster درس بارگذاری شود (نام، غیبت، نمره حضور سیستمی).
4. برای هر دانشجو نمره مشارکت ۰–۱۰ وارد کنید.
5. دکمه **«ثبت نمرات مشارکت و قفل»** را بزنید.
6. انتظار: toast موفقیت، انتقال به `grades_locked`، badge وضعیت «نمرات قفل شد».

---

## تست فرایند ۶۴ — گزارش PDF (مدرس)

1. instance فرایند ۶۴ را در پنل مدرس باز کنید.
2. پنل `film-observation-course-completion-panel` باید stepper و راهنمای مهلت‌ها را نشان دهد.
3. در جدول، ستون گزارش PDF (آپلود نشده یا لینک) و نمره گزارش ۰–۸۲ را بررسی کنید.
4. نمره گزارش وارد کنید؛ ستون **جمع** و **وضعیت** (PASS/FAIL/مرزی) به‌روز شود.
5. برای نمره مرزی ۶۴–۷۳، بلوک راهنمای SMS مرزی نمایش داده شود.
6. **«ثبت نمرات گزارش و قفل»** → انتقال به `grades_locked`.

---

## تست فرایند ۶۴ — دانشجو (آپلود گزارش)

1. با حساب دانشجو، instance فرایند ۶۴ را در تب فرایندها باز کنید.
2. پنل `student-film-observation-course-panel` با stepper و بنر مهلت آپلود (جلسه ۱۷–۱۸) نمایش داده شود.
3. بخش `film-observation-final-report-upload-section` باید شامل input فایل PDF و دکمه **«ثبت گزارش پایانی»** باشد.
4. یک فایل PDF انتخاب کنید → toast موفقیت آپلود → دکمه ثبت را بزنید → toast «گزارش پایانی ثبت شد».
5. پس از ثبت، پیش‌نمایش PDF و زمان آپلود در InfoTile دیده شود؛ فرم عمومی پایین صفحه نمایش داده **نشود**.
6. با حساب مدرس همان درس را باز کنید → در جدول، ستون **گزارش PDF** لینک فایل آپلودشده را نشان دهد (`enrich_film_reports`).

---

## تست فرایند ۶۴ — دانشجو (وضعیت پس از نمره)

1. با حساب دانشجو، instance فرایند ۶۴ را در تب فرایندها باز کنید.
2. پنل `student-film-observation-course-panel` با راهنمای آپلود PDF (جلسه ۱۷–۱۸) نمایش داده شود.
3. در صورت وجود `final_report_pdf` در context، پیش‌نمایش فایل دیده شود.
4. در صورت نمره مرزی در context، راهنمای امتحان مجدد نمایش داده شود.

## نکات

- نمرات حضور و TA در فرایند ۷۵ سیستمی‌اند؛ مدرس فقط مشارکت را ثبت می‌کند.
- جمع نمره در فرایند ۶۴: مشارکت (۱۰) + حضور (۸) + گزارش (۸۲) = ۱۰۰.
- اتوماسیون کامل امتحان مجدد و SMS هنوز در متادیتا state جدا ندارد؛ UI فقط راهنما و نمایش context است.
