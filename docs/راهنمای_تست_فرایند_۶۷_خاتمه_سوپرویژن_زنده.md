# راهنمای تست فرایند ۶۷ — خاتمه درس سوپرویژن زنده

## پیش‌نیاز

1. بارگذاری متادیتا: `live_supervision_course_completion.json`
2. کاربر مدرس در lane `instruction` پنل Staff
3. دانشجو با `lms.enrolled_courses` شامل درس سوپرویژن زنده

## سناریو ۱ — حضور دوگانه (مدرس)

1. استارت instance فرایند `class_attendance` با `course_type: live_supervision`
2. باز کردن پرونده در پنل مدرس
3. پنل **حضور دوگانه سوپرویژن زنده** نمایش داده شود
4. برای هر دانشجو: عادی / پشت‌آینه / غایب انتخاب و ثبت
5. بررسی `extra_data.lms.live_supervision[course_code]` — افزایش شمارنده‌ها

## سناریو ۲ — پیاده‌سازی پشت‌آینه (دانشجو)

1. استارت `live_supervision_course_completion` برای دانشجو
2. trigger سیستمی `mirror_attendance_recorded` → state `mirror_implementation_pending`
3. در پورتال دانشجو: پنل پیاده‌سازی + فرم
4. `mirror_write_submitted` → بازگشت به `sessions_in_progress`

## سناریو ۳ — ارزیابی نهایی (مدرس)

1. پس از ۱۵ عادی + ۳ پشت‌آینه: `eighteenth_attendance_recorded`
2. state `final_eval_pending` — پنل ارزیابی نهایی
3. تکمیل سوال ۷ و ۸ → `final_eval_submitted` → `completed`
