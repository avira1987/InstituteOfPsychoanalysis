# قالب تولید بستهٔ تست (قابل انتقال به چت دیگر)

این سند **فقط قالب، ساختار فایل و روش تولید** را توضیح می‌دهد — بدون محتوای اختصاصی یک موضوع تست.  
برای ساخت بستهٔ تستِ کار انجام‌شده در چت دیگر، بخش **«پرامپت آماده»** در انتها را کپی کنید.

> **راهنمای تست ساده PDF (اپراتور غیرفنی، سایت واقعی):**  
> برای مخاطب بدون دانش فنی روی `https://lms.psychoanalysis.ir/` از قالب جداگانه استفاده کنید:  
> **`docs/قالب_تولید_راهنمای_تست_ساده_PDF.md`** — الگو: `docs/راهنمای_تست_ساده_فرایندهای_حیاتی.pdf`

## ۲. قوانین زبان و سبک (الزامی)

| مجاز | ممنوع |
|------|--------|
| فارسی ساده و روان | جملات انگلیسی |
| «پنل دانشجو»، «منو → …»، «کارهای منتظر» | مسیر فنی مثل `/panel/portal/...` |
| «مشکل» | bug، باگ |
| «مهلت پاسخگویی» | SLA |
| «الوکام»، «درگاه بانکی» | Alocom، API، mock |
| نام کاربری/رمز در جدول (برای ورود آزمایشی) | کد فرایند مثل `start_therapy` |
| ☐ قبول / ☐ مشکل | اصطلاحات برنامه‌نویسی، seed، localhost |

**فرض‌های سامانه (در بخش «نکات مهم» بنویس):**
- کلاس آنلاین از طریق **الوکام** فعال است.
- **پرداخت بانکی** (زیبال / زرین‌پال / سامان) فعال است.
- کارنامه و گواهی به‌صورت **متن** در پنل نمایش داده می‌شود.
- بعضی مراحل **خودکار** هستند.

### نکات مهم (الوکام، پرداخت، کارنامه، خودکار)

## ۵. روش تولید فایل Word

### پیش‌نیاز
- فونت: `app/assets/fonts/IRANSans-Regular.ttf`
- کتابخانه: `python-docx`
- اسکریپت الگو: `scripts/generate_institute_onboarding_test_guide_docx.py`

### مراحل برای بستهٔ جدید

1. **دو فایل markdown ساده** را در `docs/` بساز:
   - `docs/[slug]_test_guide_plain_fa.md`
   - `docs/[slug]_role_daily_tasks_plain_fa.md`

2. **اسکریپت Word** را کپی کن (یا همان را ویرایش کن):
   - `scripts/generate_[slug]_test_guide_docx.py`
   - این دو خط را عوض کن:
     ```python
     OUT_DOCX = ROOT / "docs" / "[نام_فارسی_خروجی].docx"
     SOURCES = [
         ROOT / "docs" / "[slug]_test_guide_plain_fa.md",
         ROOT / "docs" / "[slug]_role_daily_tasks_plain_fa.md",
     ]
     ```

3. **اجرا** از ریشهٔ ریپو:
   ```bash
   python scripts/generate_[slug]_test_guide_docx.py
   ```

### ویژگی‌های Word خروجی (اسکریپت الگو)
- راست‌چین کامل (`bidiVisual`، تراز راست، جداول RTL)
- فونت **ایران‌سنس** (`IRANSans`) با جاسازی داخل فایل
- صفحهٔ جلد + صفحه‌بندی بین دو بخش markdown
- تبدیل خودکار: سرتیترها، جداول، لیست‌ها، چک‌لیست `☐`
